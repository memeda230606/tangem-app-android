# NFC 贴卡打开自有钱包（v3，TESTNET 待实卡验收）

## 目标与边界

卡片公开 NDEF 指向自有钱包 `com.tangem.wallet.external`，而不是微信公交卡、浏览器或官方生产包。系统是否显示确认提示、提示样式和锁屏行为由 Android / 厂商控制，应用不能保证所有手机都出现完全相同的确认框。

公开记录只是应用入口，不是卡片认证。进入钱包后，扫描、绑定、恢复和签名仍按现有前台 AES 认证及服务端校验执行。复制公开记录不能代替卡片，也不能完成或取消等待中的扫卡。

采用 Android 官方 MIME + Android Application Record（AAR）分发机制；AAR 指定安装包，不是下载网址。未安装钱包时，系统可能打开应用商店，也可能无法找到处理程序，**不保证跳转官网**。其他应用正在前台独占 NFC 时，系统不会按此后台分发路径处理。[Android NFC 文档](https://developer.android.com/develop/connectivity/nfc/nfc)

## 存储布局

| 区域 | 内容 | 权限 |
| --- | --- | --- |
| File 02，256 字节 | NLEN + `application/vnd.niubtmd.wallet` MIME 记录（公开网址）+ `android.com:pkg` AAR；其余清零 | `F0 E2`，公开读、Key 2 写、Key 0 改权限 |
| File 03，[0, 63) | 原有恢复分片记录 | `F0 11`，Key 1 认证加密读写 |
| File 03，字节 63 | 原样保留 | 同上 |
| File 03，[64, 126) | `NBSI` + v3 + 原 UUID + 原密钥版本 + 原签发时间 + 网址 SHA-256 | 同上 |
| File 03，[126, 128) | 原样保留 | 同上 |

公开区不含 UUID、卡片密钥、分片、助记词或钱包秘密。网址不再保密，不要填入凭证或客户信息。File 03 的网址摘要在认证读取后校验公开网址，防止被篡改内容成为可信身份的一部分。

访问权限和 Full / Plain 通信按 [NXP NTAG 424 DNA 数据手册](https://www.nxp.com/docs/en/data-sheet/NT4H2421Gx.pdf) 8.2.3.3、9.1.2 设置：仅通过免费读权限时使用 Plain；认证会话中的 Plain 命令同样增加命令计数器。

## 升级顺序

1. **先安装新版钱包，再安装 v1.5.0 写卡助手。** 钱包优先使用后续生成的 `releases/Tangem钱包-快速扫卡重试及应用唤起-20260906.apk`（包含本功能及快速贴卡重试修复）。旧钱包不支持已迁移的 v3 卡；新版保留 v2 读取。
2. 在写卡助手中确认写入后再贴一张 TESTNET 卡，保持贴紧直到显示成功。
3. 迁移先读取并保存原身份和整个 File 03 快照；任何认证、通信或未知格式错误均停止，不把旧卡自动当作新卡分配 UUID。
4. 锁定 File 02 → 写入并回读私有身份 → 完整替换并回读 256 字节 File 02 → 确认恢复区未变 → 最后开放公开读并回读。
5. 如果公开文件写入中断，保留已写好的私有身份，重试时继续使用原 UUID。未知或损坏的私有身份会停止，不能静默覆盖。此流程不是跨文件硬件事务，写入中不要移卡。
6. 成功后移开卡片，返回桌面，再贴卡测试应用打开。不要在助手独占 NFC 时测试冷启动。
